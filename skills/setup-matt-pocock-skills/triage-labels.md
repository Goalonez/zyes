# Triage Labels

这些 skills 使用五种规范 triage 角色进行表达。此文件将这些角色映射到本仓库 issue tracker 实际使用的 label 字符串。

| Label in mattpocock/skills | Label in our tracker | 含义                                 |
| -------------------------- | -------------------- | ------------------------------------ |
| `needs-triage`             | `needs-triage`       | Maintainer 需要评估这个 issue        |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息               |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，已准备好交给 AFK agent     |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现                         |
| `wontfix`                  | `wontfix`            | 不会采取行动                         |

当某个 skill 提到一个角色（例如“应用 AFK-ready triage label”），使用此表中对应的 label 字符串。

编辑右侧列以匹配你实际使用的词汇。
